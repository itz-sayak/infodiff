# infodiff — echo-corrected information diffusion

How fast do markets absorb scheduled macro news, and how much of the response is the news
itself versus the market re-trading its own reaction?

`infodiff` fits a **multiscale, state-space, exogenously marked Hawkes model (MSX-Hawkes)**
to δ-crossing price events in EUR/USD, USD/JPY, XAU/USD, the S&P 500, BTC and ETH around
eleven release types (CPI, NFP, PPI, retail sales, GDP, jobless claims, FOMC statement and
press conference, ECB decision and press conference, BoJ), 2022-01 to 2026-08.

- **Concave, certified estimation.** Every parameter enters linearly: phase-type
  (Erlang) kernel dictionaries on log-spaced time scales from 5 ms to 10 min, news kernels
  modulated by surprise marks, anticipation kernels, and a time-of-day baseline. The MLE is
  global. It is found with SQUAREM-accelerated EM plus an interior-point Newton polish, and
  each fit comes with a Fenchel duality-gap certificate.
- **Closed-form echo correction.** The fitted model is a linear Markov system. Its
  generator is Hurwitz exactly when ρ(G) < 1. The full news response C e^{𝒜t} z₀
  gives absorption quantiles (t₅₀, t₉₀), amplification, and price drift after a
  surprise, all without simulation.
- **Built-in falsification.** Every release type has a matched placebo type at the same
  clock time on days without any scheduled release (first- or second-tier). The
  news-kernel penalty is chosen by held-out likelihood.
- **EPT-TPP.** A neural temporal point process with an exact compensator (Erlang-chain
  latent state), bounded hazard heads, and a residual linear Hawkes backbone.

## Headline results

| | |
|---|---|
| Direct news kernel, median t₅₀ | ≈ 1 s |
| Echo-corrected t₅₀ (CPI, NFP, PPI, FOMC) | 16–137 s |
| Echo-corrected t₉₀ | 5–11 min |
| Branching ratio ρ(G), pooled | 0.87 (0.91 in 2022 → 0.85 in 2026) |
| Release types beating their placebo | CPI 8.5×, NFP 6.7×, PPI 4.0×, FOMC 3.9×, retail 1.9× |

Benchmarks:
- **LOBSTER order books** (test log-likelihood per event). MSX-auto beats every
  classical Hawkes estimator on AMZN, GOOG, INTC and MSFT. On AAPL, tick-EM is slightly
  ahead (3.370 vs 3.361), and EPT-TPP with the Hawkes backbone is best overall (3.380).
- **Synthetic kernel recovery.** MSX-auto is within 10⁻³ nats/event of the true model in
  all five scenarios. It has the lowest deficit on hump-shaped, multiscale and network
  kernels. tick is better on a pure exponential kernel (ExpKern 0.05 vs 0.24 ×10⁻³) and
  on a power law (SumExp 0.18 vs 0.33 ×10⁻³).
- **Public neural-TPP datasets.** See `manuscript/main.pdf`.

## Reproduce

```bash
python -m venv .venv && .venv/Scripts/pip install -e .[dev]    # plus tick for classical baselines
cp .env.example .env    # FRED_API_KEY (required); TrueFX credentials optional

python scripts/download_ticks.py histdata     # FX/gold/S&P ticks
python scripts/download_ticks.py binance      # BTC/ETH aggTrades
python scripts/build_panel.py                 # windows + placebos per year -> data/processed/
python scripts/select_l1.py                   # held-out choice of the news-kernel penalty
python scripts/run_main.py 2022               # one year (repeat per year)
python scripts/run_main.py 2022,2023,2024,2025,2026 pooled
python scripts/run_track_d.py                 # forecasts for 2025-26 releases

python scripts/run_track_a.py                 # synthetic recovery
python scripts/run_track_c_classical.py aapl,amzn,goog,intc,msft
python scripts/run_ept.py lob_aapl 0,1,2 auto # EPT-TPP (GPU)
python scripts/gpu_queue.py gpu               # runs results/gpu_jobs.txt one job at a time

python scripts/make_tables.py && python scripts/make_figures.py && python scripts/make_dashboard.py
cd manuscript && tectonic -X compile main.tex
pytest
```

Run only one CUDA process at a time on small GPUs (use `gpu_queue.py`). CPU jobs should set
`CUDA_VISIBLE_DEVICES=-1` and cap threads (`scripts/cpu_env.sh`).

## Data notes

- Tick data: HistData (FX, gold, S&P 500 CFD; timestamps EST, converted to UTC) and
  Binance USDⓈ-M aggTrades.
- Release values: first prints from ALFRED vintages.
- Surprises: Cleveland Fed inflation nowcasts, Atlanta Fed GDPNow, and statistical
  forecasts from real-time vintages.
- LOBSTER: the free 2012-06-21 samples, with 100 ns jitter on tied timestamps.
- Raw data is not redistributed; `data/` is gitignored.
